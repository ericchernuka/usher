# Domain docs

This repo has one domain shared by core, Vite, React, and Cloudflare.

Before exploring domain behaviour, read root GLOSSARY.md. Before proposing a design change, also read relevant decisions in docs/adr/.

Use glossary terms in code discussions, tests, issues, and proposals. Flag conflicts with an existing ADR before proposing a different decision.

Create ADRs only when a resolved trade-off needs a lasting explanation. If the ADR folder or a relevant document does not exist, continue without creating a placeholder.
